픽셀디펜스 Stage 1 배경 + 방패병/궁수 스프라이트 재적용 최종 버전

수정 핵심
1. Stage 1 숲/초원 배경 유지
2. 주인공도 임시 SD 기사 스프라이트로 표시
3. 방패병(type: guard)에 SD 기사 스프라이트 적용
4. 궁수(type: archer)에 궁수 스프라이트 적용
5. 이미지 경로 문제를 줄이기 위해 script.js 안에 내장 이미지 백업을 추가했습니다.
   - 같은 폴더의 PNG를 못 읽어도 내장 데이터로 다시 불러오도록 처리했습니다.
6. asset_check.html 추가
   - 배경/방패병/궁수 이미지가 정상 보이는지 먼저 확인할 수 있습니다.

실행 방법
- index.html, style.css, script.js 파일과 아래 PNG 파일들을 같은 폴더에 두고 실행
- stage1_forest_bg_v2.png
- guard_spritesheet_v2.png
- archer_spritesheet_v2.png

주의
- 이번 버전부터 처음부터 보이는 주인공도 SD 기사 스프라이트로 표시됩니다.
- 방패병 스프라이트는 1번 키 또는 방패병 소환 버튼을 눌러야 확인됩니다.
- 궁수 스프라이트는 2번 키 또는 궁수 소환 버튼을 눌러야 확인됩니다.
